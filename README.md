# Podcast Automixer is retired

Development of this project ended on October 10, 2026.

Use [CleanSlate / Podcast Bleed Reducer](https://github.com/Today20092/podcast-bleed-reducer),
the replacement application written in Rust.

The entire old project is retired: the Python CLI and desktop app, audio-processing
engine, report and desktop interfaces, packaging work, unfinished experiments,
and editor/DAW integration roadmap. No further development or feature releases
are planned here.

Existing [PyPI versions](https://pypi.org/project/podcast-automixer/) and
[GitHub releases](https://github.com/Today20092/podcast-automixer/releases) are legacy
software. This repository retains the source and documentation for reference.
Old commands, settings, and project files are not a migration contract for CleanSlate.

See the [retirement inventory](docs/retirement.md) for what was built and retired.
